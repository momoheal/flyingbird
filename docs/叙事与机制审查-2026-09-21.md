# 叙事与机制审查与改造记录（2026-09-21；2026-09-23 更新）

## 基线与结论

本轮以 `星火燎原-多视角剧情小说.md` 为剧情事实来源，并按 `剧情设计文档.md` 改造 HTML 原型。改造前原型沿用旧 B 区二选一流程：`protection/execute` 在第二章写入 `branch`，随后调用两种分支 Boss 并结束整局。该流程与“前两章只收集证据、仅第 09 隔离关口决定路线”的现行设定不兼容。

旧 B 区最终选择和两种分支 Boss 已从运行时流程移除。原型已从单一叙事纵切继续扩展为九章故事线的可走通骨架：公共段覆盖序章至第五章，第 09 关口后依路线进入第六、七或八章，最后抵达对应的第九章终局。完整度不等同于正式内容量；尚未实现的角色演出、专属 Boss、美术、音频与数值工作明确列在 `全剧情细节完善路线图.md`。

```text
     -> seal_gate      -> 第七章：安静的胜利 -> 第九章帝国终局
     -> deep_rock      -> 第八章：深岩之下 -> 第九章深岩终局
  -> 结果摘要与重新部署
```

## 叙事事实与机制映射

| 环节 | 剧情/机制审查 | 已实施的最小闭环 |
| --- | --- | --- |
| 序章与第一章 | 需要交代三人互救、六秒跃迁窗、Bob 接口超载，以及赵利俄斯护航异常的证据。 | 序章以可跳过回放交代关系；第一章保留儿童面罩/外焊舱门、三次航母保护性转向与伪造战报对照。 |
| 第二章 | B 区应提供黑匣证据，不能承担阵营定夺。 | 三次扫描写入离线黑匣后进入过场；不显示阵营卡、不写路线。 |
| 第三、四章 | 在 Gate 09 前，玩家必须亲自完成“公开证据”和“定位锈蚀航路”，避免仅靠对白跳过因果。 | 第三章使用 `survive`，守住公共证据中继并清空波次；第四章使用 `collectUpload`，回收核心并在维修站上传。 |
| Gate 09 | 三种行动应是具体风险抉择，而非善恶阵营按钮。 | 选择卡分别写入 `break_blockade`、`seal_gate`、`deep_rock`；此处是唯一写入 `route` 的入口。 |
| 第六、七、八章 | 路线选择应有后果，不能在选择后立刻播放结局。 | 三条路线分别进入“名字的重量”“安静的胜利”“深岩之下”，以破坏节点、防守或回收上传承接路线语义。 |
| 第九章 | 终局需要落在赵利俄斯外环，并带回先前证据与代价。 | 三种第九章配置有独立目标、保护对象/上传点和结果对白；终局摘要目前为文本骨架，证据档案卡待补。 |
| 失败与重试 | 每个战斗段都应能清晰失败、重试且不污染后继状态。 | 关口和通用章节均在玩家/保护对象失守时进入失败卡，并可从本章重试；进入新章节时清空上一个关卡上下文。 |
| 驾驶员能力 | 三名角色的主动能力不能只在开头章节可用。 | Alice、Bob、Charlie 的能力可用于关口和通用故事章节；Bob 导弹可锁定章节战术节点。 |

## 当前机制契约与风险

1. `route` 仅能由 Gate 09 三选项写入；B 区及公共章节只写证据或章节状态。
2. 通用章节的胜利条件同时要求完成专属目标、守住保护对象（如配置）并清空配置波次，避免玩家冲刺互动目标跳过战斗。
3. `startChapterFive()` 与 `startStoryChapter()` 必须互斥清理 `gate09`、`storyChapter` 等战斗上下文，防止旧目标在新章节继续受伤或写入状态。
4. 当前敌人、程序绘制背景和部分目标造型仍有复用；它们只证明流程可玩，不能替代章节专属敌人、Boss 或正式美术。
5. 角色头像、持续证据档案、终局代价摘要和分支前后的关系变化仍不足。这些已作为后续最高优先级叙事补完项记录在路线图 A 批。
