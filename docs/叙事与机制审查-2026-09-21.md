# 叙事与机制审查与改造记录（2026-09-21）

## 基线与结论

本轮以 `星火燎原-多视角剧情小说.md` 为事实来源，并按 `剧情设计文档.md` 的叙事纵切改造 HTML 原型。改造前原型是旧版 B 区二选一流程：`protection/execute` 在第二章写入 `branch`，随后使用两种分支 Boss 并结束整局。该流程与“前两章只收集证据、仅第 09 隔离关口决定路线”的现行设定不兼容。

已将旧 B 区最终选择和两种分支 Boss 从运行时流程移除。`背景故事与台词文档.md`、`需求文档.md`、`架构文档.md` 中的旧方案已加显著历史说明，避免它们继续覆盖小说与剧情设计文档。

## 叙事改造

### 新的运行时链路

```text
赵利俄斯护航战回放（可跳过）
  -> 第一章：镇压与谎言
  -> 黑匣/军需官过场
  -> 第二章：检疫井之前（护航、三次扫描、无路线选择）
  -> 锈蚀插章（真实风险、越权位置包、第 09 关口告警）
  -> 第五章：第 09 隔离关口
  -> seal_gate / break_blockade / deep_rock
  -> 对应独立目标与结局结果卡
```

### 已落实的剧情事实

- 序章交代 Alice、Bob、Charlie 在赵利俄斯护航战中的互救关系、六秒跃迁窗与 Bob 接口超载。
- 第一章保留救生舱儿童面罩/外焊舱门证据；航母加入三次可记录的保护性转向，战后以航迹回放与伪造战报并列呈现。
- 第一章普通波次恢复帝国无人机与改装叛军艇混合，避免把现场写成单一阵营靶场。
- B 区三次扫描结束后写入离线黑匣，直接进入插章；不显示阵营卡、不写入路线。
- 插章明确区分“余烬感染”政治标签和真实锈蚀风险，并交代帝国扩大名单、余烬利用民船、Bob 协处理器越权以及关口塌方。
- 关口选择之前呈现玛拉求救、永久封门、爆破船与塌方三重危机；三张选择卡显示行动与即时风险，不使用“善/恶”或“正确阵营”文案。
- 三条路线拥有不同胜利条件、保护对象、通讯和结果摘要：
  - `seal_gate`：摧毁爆破武器节点，保护医疗补给线。
  - `break_blockade`：解除三道牵引锁，保护难民船队。
  - `deep_rock`：回收过滤核心，在临时过滤舱旁上传黑匣。

## 机制审查与改造

| 项目 | 审查结果 | 已采取措施 |
| --- | --- | --- |
| 开场扫描可玩性 | 原实现虽然在扫描状态生成子弹，却没有在该状态更新/绘制投射物，HUD 还称“武器锁定”。 | 扫描时完整更新、绘制和清理玩家投射物；救生舱不进入任何伤害碰撞；HUD 明确显示“主炮在线，救援舱免疫”。 |
| 第一章证据可观察性 | 航母保护行为主要是台词/静态逃生舱，缺少可计数的游戏事件。 | 增加三次保护性转向提示、`carrier_protective_turns` 证据标记和章节结算航迹回放。 |
| 第二章叙事节奏 | 证据收集后被旧路线卡和 Boss 强制打断。 | 保留护航、三次扫描、扫描信标补发和失败重试；完成条件现在唯一导向黑匣/插章。 |
| 选择与玩法后果 | 旧卡片只变更阵营、敌机和文本，结局不存在。 | Gate 09 中每条路线配置不同目标实体、压力波、可损毁保护对象和结果卡。 |
| 失败/重试 | B 区有重试，但没有关口统一处理。 | 第 09 关口在玩家或救援目标失守时保留当前驾驶员/改装并从关口前段重试；整局重新部署走完整重置。 |
| 角色能力 | 原有三名角色的主动能力只在第一、二章被允许使用。 | Alice、Bob、Charlie 的能力扩展至关口前段和路线终局；Bob 导弹可锁定路线战术节点。 |
| 叙事回归检查 | 原 `run_checks.ps1` 只验证旧版第二章分支台词和素材。 | 新增对白 ID、状态、路线 ID 和旧分支符号的静态契约检查。 |
