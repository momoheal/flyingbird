# 第一章美术素材需求与一行 Prompt

## 使用方式

每个素材下面都提供一行完整 prompt，可直接复制给图像生成工具。每行已经包含：文件名、尺寸、格式、透明/不透明模式、视角、用途、主体描述、风格要求和禁止项。

## 通用规则

- 运行时素材放在 `assets/ch01/<category>/`。
- 预览图放在 `assets/ch01/_previews/`，不作为游戏运行素材。
- 文件名使用英文小写、下划线和尺寸后缀。
- 战机、敌机、Boss、特效使用透明 PNG。
- 背景使用不透明 PNG。
- 不要在图片里生成文字、logo、水印、签名。

## 命名规则

```text
sf_ch01_<category>_<object>_<variant>_<size>.png
```
