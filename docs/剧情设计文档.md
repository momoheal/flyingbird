# 《星火燎原》剧情设计文档

## 1. 文档定位

本文件是小说到游戏原型的实现映射。`星火燎原-多视角剧情小说.md` 是人物动机、事件因果和结局含义的唯一事实来源；本文件只定义玩家在原型中如何经历这些事件，不得以玩法方便为由改写小说中的价值冲突。

当前目标是完成一条可重复游玩的叙事纵切：玩家从赵利俄斯护航战进入 A 区与 B 区调查，在第 09 隔离关口做出不可逆选择，并体验帝国、叛军或深岩三条短终局。

## 2. 体验支柱

1. 玩家先看到矛盾证据，再做选择。命令、航迹、名单和现场救援必须彼此冲突，不能在开场直接宣布任何阵营正确。
2. 三名队员不代表善恶阵营。Alice 看见眼前的人，Bob 关注可验证的风险与系统接管，Charlie 关注行动留下的后果；三人都必须在关键事件中有合理且不完整的判断。
3. 选择产生具体后果。分支的差异体现在任务目标、敌方行为、通讯内容、获救者处境与结局，而不只更换结算文字。
4. 伤害通过通讯、航迹、物资和环境传达。原型不展示处决或屠杀画面。

## 3. 原型流程

```text
序章过场：赵利俄斯护航战
  -> 第一章可玩：镇压与谎言
  -> 整备过场：黑匣航迹与 B 区货单
  -> 第二章可玩：检疫井之前
  -> 插章过场：旧友分歧、锈蚀证据与第 09 关口告警
  -> 第五章可玩：第 09 隔离关口
  -> 帝国线 / 叛军线 / 深岩线短终局
  -> 对应结局、结果摘要与重新部署
```

前两章只积累证据与角色关系，不决定最终路线。最终路线仅由第 09 隔离关口的三选一写入。

## 4. 章节设计

### 4.1 序章：赵利俄斯护航战

| 项目 | 设计 |
| --- | --- |
| 形式 | 可跳过的战术过场，首次运行自动播放。 |
| 目的 | 建立 Alice、Bob、Charlie 曾互救并被编入裁决者小队的共同历史。 |
| 事件 | Alice 拖住难民船；Charlie 以装甲挡火；Bob 计算六秒跃迁窗并承受接口过载。 |
| 玩家信息 | 三人曾经信任彼此，帝国的“裁决”曾被他们理解为结束战争。 |
| 完成条件 | 玩家可点击推进或跳过；不产生战斗数值与分支。 |

### 4.2 第一章：镇压与谎言

保留既有 A 区救生舱扫描、混合波次和缝合航母 Boss。第一波前依次呈现驾驶员身份、三项命令与七号补给船求救；扫描发现儿童呼吸面罩和被外部焊死的舱门。Boss 至少两次为逃生舱挡碎石或火力，战后战报却伪称其袭击民用目标。

本章写入证据 `carrier_protective_turns`。战后整备使用航迹回放和军需货单引出 B 区，而非将航母击毁写成“平叛胜利”。

### 4.3 第二章：检疫井之前

玩家护航被伪装成矿务转运船的船队，收集三份证据：原始货单为紧急转运、生命信号远超编制、身份码被批量注销且逃生门从内部锁死。净化倒计时出现后，玩家的即时目标是守住跃迁窗口和救援浮标，而不是决定谁应被消灭。

章节末根据战斗表现生成完整黑匣与名单副本，并播放 Alice、Bob、Charlie 对“证据是否足以行动”的分歧。此处不显示阵营二选一，也不锁定路线。

### 4.4 插章：锈蚀的航路

以短通讯与可跳过转场交代三项事实：锈蚀症真实存在；帝国正在扩大净化名单；余烬也会把难民和风险当作战争工具。Bob 的协处理器尝试越权发送位置包，Charlie 看到封锁救人和封锁害人的并存结果，Alice 收到第 09 关口塌方求救。

插章结束必须让玩家知道：没有等待“正确阵营”的空间，下一次决定必须面对具体的人与系统性风险。

### 4.5 第五章：第 09 隔离关口

| 要素 | 设计 |
| --- | --- |
| 可见危机 | 帝国即将永久封门；余烬准备炸墙；避难所底层塌方，玛拉请求救援。 |
| 共通前段 | 玩家一边抵御封锁无人机与失控锈蚀单位，一边维持临时救援信号。Bob 提出临时隔离舱方案，Charlie 要求明确撤离余量。 |
| 选择时机 | 塌方区和两方舰队都进入倒计时后暂停，显示三个行动及其即时、可见的代价。 |
| 选择原则 | 三项都不是“善良/邪恶”按钮；文案描述行动与风险，不泄露结局评价。 |

选择如下：

1. `seal_gate` 协助封控：掩护医疗通道并阻止爆破船，代价是部分门内人员被永久隔离。
2. `break_blockade` 冲破封锁：破坏牵引束、为船队打开窗口，代价是锈蚀扩散风险与余烬的民船战术。
3. `deep_rock` 先救塌方区：轰开外壁、建立临时隔离舱并转运幸存者，代价是无法完全阻止封门或冲关，且资源极度不足。

## 5. 路线与短终局

### 5.1 帝国线：安静的胜利

玩家协助守住封锁并在终局拦截携带黑匣协议的深岩运输船。Bob 与 Charlie 以叛军身份出现，但其目标是让被注销者获得可见的申诉渠道。玩家战斗目标是摧毁叛军旗舰的武器节点，同时保护医疗补给线；胜利后 Alice 获得勋章，却听到门内白噪与被中断的玛拉频道。结局强调秩序维持的现实代价，而不是歌颂镇压。

### 5.2 叛军线：名字的重量

玩家带领船队冲出封锁，终局面对 Bob 的帝国旗舰。战斗目标是解除牵引锁、维持难民船完整度并避开民船；Charlie 反对余烬用平民掩护突击。结局中船队逃离，但感染传播与余烬狂热派留下新的风险；Alice 拒绝被宣传成火种。结局强调自由不等于免于责任。

### 5.3 深岩线：深岩之下

玩家救出塌方区幸存者，终局是防御临时隔离舱、回收过滤核心并将黑匣证据送入公共广播。帝国与余烬都成为施压方，但任何一方都不是纯粹的最终敌人。结局建立由工人、医生和工程师共同管理的深岩联合体：局部隔绝、减毒改造与公开复核并存。该路线不是隐藏完美结局，而是选择承担缓慢、资源不足和持续协商的代价。

## 6. 对话与运行时数据

- `docs/dialogue-story.md` 是原型唯一加载的运行时对白源，保持单个 YAML 围栏与 ID 唯一性。
- 新增 ID 分组：`prologue.*`、`ch02.outro.*`、`interlude.*`、`ch05.*`、`ending.empire.*`、`ending.rebel.*`、`ending.deep_rock.*`。
- 每个关键事件至少包含一个默认台词和 Alice、Bob、Charlie 三个驾驶员变体；角色差异不得只替换姓名。
- 普通通讯写入右上通讯面板，不阻断移动与射击；选择、终局结果和结局文本进入全屏卡片并暂停。
- 原型运行状态至少包含 `PROLOGUE`、`CH01_*`、`CH02_*`、`INTERLUDE`、`CH05_PLAY`、`CH05_CHOICE`、`ENDING_PLAY`、`ENDING_RESULT` 与 `RESULT`。

## 7. 验收标准

1. 首次进入可播放或跳过序章；三名队员的互救关系在第一章前可被理解。
2. 第一章的救生舱证据、航母保护行为和伪造战报仍完整可见。
3. 第二章在不进行阵营选择的前提下完成护航、三次扫描和黑匣留存。
4. 第 09 关口同时呈现永久封控、炸墙风险、塌方救援和玛拉求救；玩家可清楚理解三个行动各自的即时代价。
5. 三个关口选择均进入不同的战斗目标、通讯组和结局摘要。
6. 帝国、叛军和深岩结局都承认锈蚀症为真实风险，且不把任何阵营写成纯粹正义或邪恶。
7. 任一结局后可重新部署，不会残留前一局的路线、护航船、Boss 或对话状态。
8. `tools/run_checks.ps1` 保持通过；对话数据校验扩展为验证新增关键 ID。

## 8. 非目标

- 本轮不实现小说全部九章的完整战役，也不扩展局外成长、联网或 iOS 正式客户端。
- 不新增血腥处决表现，不以路线颜色替代文字和图形提示。
- 不把深岩线设计为没有代价的“真结局”。
