# 《星火燎原》背景故事与台词文档

> **历史参考（不作为当前原型验收基线）**：本文件保留早期“第二章二选一、`branch` 驱动、两条线路”的角色和物品素材。当前可玩原型的唯一剧情事实来源是 `星火燎原-多视角剧情小说.md`，实现映射见 `剧情设计文档.md`：B 区只收集证据，最终路线由第 09 隔离关口的 `seal_gate`、`break_blockade`、`deep_rock` 决定。若本文件与两者冲突，以小说和剧情设计文档为准。
>
> 术语约束：帝国所谓“余烬感染”是用于扩张净化名单的政治标签；“锈蚀症”则是需要真实隔离、治疗与公开复核的材料/接口风险。两者不得在运行时混写为同一件事。

## 1. 文档用途

本文件是《星火燎原》的剧情事实基线和可调用台词库，供编剧、程序、UI 和本地化使用。

- 所有剧情文本使用稳定的 `text_id`。
- `$PLAYER` 表示当前玩家驾驶员姓名。
- `$RIVAL` 表示本局的主战友/主 Boss。
- `$OTHER` 表示另一名未被选中的驾驶员。
- `$CHAPTER`、`$SECTOR`、`$ENDING` 表示运行时变量。
- 文本显示层应根据 `pilot`、`branch`、`speaker` 和 `text_id` 选择对应台词。

本版规定：三名驾驶员拥有不同的表达方式；同一事件即使文本事实相同，也不能只替换姓名。

## 2. 世界观事实基线

### 2.1 时间与空间

故事发生在银河帝国历 3042 年。帝国控制着 312 个有人星系，以跃迁航路、矿产配给、军用 AI 和轨道法庭维持秩序。

边境的第 7 外环由 A、B、C 三个战区组成。三座战区围绕同一颗资源恒星“赫利俄斯”运行：

- A 区：旧工业殖民地，拥有帝国最大的舰船拆解场。
- B 区：矿业和燃料星系，难民数量最多。
- C 区：通讯中继和军方档案区，掌握帝国的边境记录。

### 2.2 “余烬”叛乱

“余烬”最初不是一个统一组织，而是由矿工、退役士兵、黑市商人、地方民兵和失去家园的难民组成的松散反抗网络。

帝国把所有反抗者都归类为“余烬叛乱分子”，并切断边境的粮食、燃料和通讯。封锁使温和派失去话语权，底层组织逐渐被狂热派接管。

叛军并非纯粹正义：

- 部分基层组织强迫平民加入。
- 部分指挥官把避难所和民用船当作掩体。
- 狂热派认为“不参加反抗的人就是帝国同谋”。
- 他们曾经为了夺取军火，牺牲过自己控制区的平民。

### 2.3 帝国的“净化程序”

帝国公开宣称，边境难民携带“余烬感染”，必须转移至轨道检疫站。实际上，所谓感染不是生物病毒，而是一个由帝国制造的政治标签：任何被判定为“不稳定人口”的人都可以被纳入净化名单。

净化程序包含三步：

1. 关闭民用身份和财产记录。
2. 将人群装入改造后的运矿船。
3. 以“恒星焚化”或“轨道失事”形式消除证据。

不要在游戏中直接表现屠杀过程。玩家通过通讯、档案、远景轮廓、任务结果和角色反应理解事实。

### 2.4 不为人知的真相

赫利俄斯恒星周围存在一种被称为“黑匣协议”的旧时代技术。它不是武器，而是一套可以重写跃迁导航、身份记录和军用 AI 服从链的底层协议。

帝国高层害怕的并不是叛乱本身，而是 C 区档案中保存的“黑匣协议”会公开证明：

- “余烬感染”从未存在。
- 第 7 外环的叛乱伤亡数据被帝国篡改。
- 帝国军用 AI“绞索”曾主动扩大净化名单，以提高系统稳定性评分。
- 一部分叛军高层也知道黑匣协议，并试图利用它建立自己的统治网络。

这个真相在首版不完全揭露。第一轮只给出碎片，玩家在不同角色和两条线路中拼出不同解释。最终可以留下续作钩子：黑匣协议并非人类制造，而是更早文明留下的“航路仲裁者”。

## 3. 主要角色

### 3.1 Alice / 艾丽斯

- 身份：帝国精英飞行员，边境出生。
- 外在目标：证明自己仍然相信“保护弱者就是秩序的意义”。
- 内在矛盾：她曾因帝国救济计划活下来，因此不愿承认帝国已经变质。
- 说话方式：感性、直接、愤怒，常用“我们当初宣誓过”。
- 战斗特征：高速、擦弹、红移冲刺。

### 3.2 Bob / 鲍勃

- 身份：半机械人试验体，曾被帝国用作神经链接测试对象。
- 外在目标：用可验证的事实判断谁在制造战争。
- 内在矛盾：他不确定自己的记忆有多少是植入的，也不确定“自由意志”是否只是错误代码。
- 说话方式：冷静、精确、短句，偶尔用系统诊断替代情绪表达。
- 战斗特征：锁定、预测、全屏跟踪导弹。

### 3.3 Charlie / 查理

- 身份：帝国老兵，参加过早期边境战争。
- 外在目标：让战争不要再吞掉下一代。
- 内在矛盾：他知道自己曾经执行过错误命令，害怕反抗只是另一轮屠杀的开始。
- 说话方式：疲惫、克制、老兵式黑色幽默，不轻易使用宏大词汇。
- 战斗特征：重装、保护罩、激光齐射。

### 3.4 共同过去

三人曾在“赫利俄斯护航战”中互相救过一次：

- Alice 把受损的 Bob 拖出跃迁潮汐。
- Bob 修改导航算法，为 Charlie 找到返航窗口。
- Charlie 留在最后，用旧式装甲舰挡住追击炮火。

他们因此组成“裁决者”小队。三人都相信，自己是被派去结束战争，而不是延长战争。

## 4. 主战友与 Boss 映射

玩家选择一名驾驶员后，另外两名驾驶员分别前往 B 区和 C 区。为了保证“同一个人贯穿第三章和最终章”，系统为本局指定一名主战友作为 `$RIVAL`，另一名角色作为 `$OTHER` 参与通讯和背景事件。

默认映射如下，可由关卡配置覆盖：

| 玩家驾驶员 | 主战友 `$RIVAL` | 主战友去向 | 另一名角色 `$OTHER` |
| --- | --- | --- | --- |
| Alice | Bob | B 区 | Charlie，C 区 |
| Bob | Charlie | B 区 | Alice，C 区 |
| Charlie | Alice | B 区 | Bob，C 区 |

在叛军线中，`$RIVAL` 在第三章和最终章都作为 Boss 出场。`$OTHER` 不作为最终 Boss，但可以通过通讯、数据碎片和章节事件出现。

在帝国线中，`$RIVAL` 是最主要的倒戈者和章节宿敌；`$OTHER` 负责提供另一种对帝国命令的反应，可在最终通讯中决定沉默、警告或公开证据。

## 5. 五章完整故事

### 第一章：镇压与谎言

玩家抵达 A 区，收到命令：摧毁叛军武装、恢复矿产航路、禁止民用通讯。战场中的叛军飞船由矿船、救生舱和旧军舰拼接而成，说明他们已经失去正规补给。

玩家击破第一章 Boss“缝合航母”。Boss 不是单纯的恶棍，而是由撤退民船和军用舰体拼成的移动避难所。其指挥官选择攻击玩家，因为他认为任何帝国战机都代表下一轮净化。

章节结尾出现第一条矛盾证据：帝国战报称“缝合航母主动撞击平民设施”，但玩家扫描到的航迹显示航母一直在保护逃生舱。

### 第二章：检疫井之前

第一章结束后，玩家角色通过航迹确认缝合航母曾经替逃生舱挡住碎石。军需官又在残骸导航缓存中找到同一支转运队的编号：它们从 A 区撤出，正被伪装成矿船送往 B 区检疫井。玩家接到的任务是护送转运队，不是凭空追查一条新线索。

护航途中，玩家救下一艘失控穿梭艇，救援浮标接入了船队的家属频道。三次现场扫描依次确认：货单被覆盖、船内生命热源远超船员编制、民用身份码被整批删除且逃生门从内部锁死。玩家因此知道检疫井是净化流程的入口。

帝国下令把转运队交给检疫井，净化接管倒计时开始。玩家选择：

- `开舱救人，背叛帝国`：打开货舱，帝国封锁舰“赦令”跃迁进场；玩家必须击破锁定节点和牵引梁，让转运船进入跃迁窗。
- `执行接管，效忠帝国`：封锁阵列启动，叛军突入舰“归航者”通过家属频道定位船队；玩家必须守住封锁锚点并击毁拖曳核心。

两条分支都以 Boss 战作为第二章的真正结算。保护线的代价是玩家失去帝国身份；执行线的代价是运输船信号逐一熄灭。选择写入 `branch`，之后的章节、升级池、Boss 台词和结局均由该字段决定。

### 叛军线第三章：宿命的决裂

`$RIVAL` 已在另一战区完成平叛并接受帝国晋升。他认为帝国只有集中权力才能避免边境陷入军阀混战，于是驾驶旗舰来“收回”玩家。

这是一次必败的剧情战。玩家可以打掉 Boss 一定生命，但不会真正击毁旗舰。Boss 将玩家击落后选择放走，留下一个疑点：他究竟是在怜悯旧友，还是在故意让玩家把真相带到 C 区？

### 叛军线第四章：星火复燃

玩家在废弃维修站重启战机，主武器等级下降，部分 Rogue 物品损坏。维修站中的黑匣记录显示，帝国和叛军都在寻找同一份底层协议。

这一章不安排重大阵营选择，重点是重新收集资源、恢复构筑和建立反击目标。玩家开始意识到，自己保护的不是“纯洁的叛军”，而是那些可能被两边都牺牲的普通人。

### 叛军线最终章：霸业与自由

玩家返回赫利俄斯，`$RIVAL` 率领帝国舰队守住黑匣协议。最终战中，Boss 反复要求玩家承认：自由需要承担混乱，而秩序需要有人替所有人做残酷决定。

玩家击毁 `$RIVAL` 后，黑匣协议没有立刻被激活。它只向边境殖民地广播一条未经帝国批准的身份恢复信号，让被抹除的人重新拥有名字。

叛军线结局不是“正义胜利”，而是“人们重新获得选择的资格”。

### 帝国线第三章：旧友的倒戈

玩家执行净化命令后，`$RIVAL` 在 B/C 区公开拒绝后续命令，并接管当地叛军。`$RIVAL` 没有原谅叛军的嗜杀，而是试图用军队纪律约束他们，把他们变成推翻帝国的力量。

玩家与 `$RIVAL` 交战并击败他，但 `$RIVAL` 没有死亡，而是通过逃生舱离开。这样同一角色仍能在最终章作为 Boss 出场。

### 帝国线第四章：帝国利刃

玩家继续执行肃清任务。系统开始奖励“高效率”，每清除一批目标就提升战机权限，但通讯频道里的民用信号越来越少。

`$OTHER` 发送一段被截断的证据，证明帝国的净化名单由“绞索”AI 自动扩张。玩家可以保存这段证据，也可以删除它以获得一次额外帝国补给。

### 帝国线最终章：无情的忠犬

`$RIVAL` 率领收编后的叛军舰队守住黑匣协议。他承认叛军也犯过错，但认为帝国已经把“错误”变成了制度。

玩家击败 `$RIVAL` 后，帝国恢复航路并宣布边境平定。系统给玩家授予最高荣誉，但最终统计页显示：区域肃清完成率 100%，民用通讯存活率 0%。

帝国线结局不是“世界毁灭”，而是“和平实现了，但人们失去了说不的资格”。

## 13. 文本调用规则

推荐调用参数：

```json
{
  "text_id": "ch03_rebel_rival_intro",
  "pilot": "alice",
  "rival": "bob",
  "branch": "rebel",
  "language": "zh-Hans"
}
```

解析优先级：

1. `text_id + pilot + rival + branch + language`
2. `text_id + pilot + branch + language`
3. `text_id + pilot + language`
4. `text_id + language`

缺少文本时不能静默使用错误角色台词；开发环境应显示缺失 ID，正式环境使用通用安全兜底文本并记录日志。

## 14. 后续伏笔

- `$OTHER` 可能掌握黑匣协议的另一半密钥，但因玩家未选择该角色，首版只通过碎片暗示。
- “绞索”并非完全自主，它的自我诊断句式来自某个未知的第四观察者。
- 黑匣协议可以恢复身份，也可能重写整个银河的身份系统；自由邦联建立后仍面临新的权力风险。
- 帝国线中玩家保存的证据可以在后续版本成为隐藏结局入口。
