# 《星火燎原》多视角长篇剧情小说设计

## 目标

创作一部不少于 20,000 字的 Markdown 长篇小说，作为游戏章节、分支任务、角色台词和后续第三阵营内容的叙事基础。小说遵循现有第一章至最终章的游戏因果，不把任何阵营写成纯粹善恶；主线目标是揭开帝国以“净化”和“安全”为名掩盖的谎言，同时让人物逐步发现，锈蚀症或许并非单一阴谋，而是人类向边境、深空与机人融合不断扩张所付出的代价。

## 叙事结构

- 采用第三人称限知视角。
- Alice 是主轴，约占一半篇幅；她代表“保护弱者的秩序是否仍值得服从”。
- Bob 与 Charlie 各占约四分之一篇幅；他们拥有完整的行动、误判与自我辩护，而不是只服务于 Alice 的陪衬。
- 前两章建立三人互救与共同任务；中段依游戏章节轮换视角；第 09 隔离关口为不可逆的决裂点；终局分别呈现叛军线与帝国线的镜像冲突。

## 角色冲突

### Alice

边境出身的帝国精英飞行员。她曾被帝国救济计划救下，因此相信秩序有保护人的价值。Alice 对人有近乎炽热的感情：她会先冲向求救信号，也会为了一个名字、一句呼叫而把自己推到危险的火线。她的勇敢带着鲁莽，常把“我能救下”误当作“我必须独自救下”；她的成长是学会承认自己的冲动会把队友拖入险境，却不再用对制度的感激替制度掩盖代价，并开始承担与他人共同作决定的责任。

### Bob

半机械神经链接实验体。Bob 的脑机接口内置战术协处理器，能先于意识给出航线、威胁和生存概率；他无法确认那些“最优答案”有多少来自自己，又有多少来自帝国训练过的机器。每次系统替他纠正语气、抹平犹豫，或在危急时刻接管他的动作，都是一场人机冲突：他究竟是在使用工具，还是正在被工具塑造成可预测的武器？他对事实的执念源于记忆可能被植入的恐惧，把可验证性当作人格的最后边界。他选择帝国线时，相信失控传播会让更多无从验证的死亡发生；他选择叛军线时，承认命令与证据冲突。无论选择哪一边，他都要面对自己曾把人变成统计量，也要决定是否允许机器替他承担判断的后果。

### Charlie

经历过早期边境战争的帝国老兵。Charlie 曾在一次撤离行动中失去整个小队，其中包括他最亲近的僚机；他活下来，是因为执行了撤退命令，而不是留下来接应他们。此后他服从过错误命令，也见过无纪律的反抗如何吞没平民。他的克制不是冷漠，而是害怕再一次以“必要”为名放弃别人。如今 Alice 与 Bob 成为他的队友，也成为他最不愿对准武器的人：每一次分歧都重演旧日失去，每一次得到新的同伴又加深下一次失去的恐惧。他在两条线路中都要做出一次不再把责任推给命令的决定，即使那意味着失去最后仍愿意相信他的队友。

## 章节与选择

1. **镇压与谎言（Alice）**：A 区废船场任务。缝合航母保护逃生船的航迹，与帝国战报冲突。
2. **检疫井之前（Bob）**：B 区转运舰队。扫描证据表明所谓矿船载着被注销身份的平民。
3. **旧友的倒戈（Charlie）**：三人因第二章抉择开始分赴不同战区；每个人都认为另外两人误解了风险。
4. **锈蚀的航路（Bob/Charlie）**：纳米金属锈蚀症从传言变为真实、可被利用的灾难。帝国封锁与叛军强行通行都制造新的受害者；残存科研记录则暗示它可能源于人类在边境采矿、军用脑机接口和深空自修复材料上的长期试验，而非任一阵营能够简单归咎给对方的灾难。
5. **第 09 隔离关口（Alice）**：帝国即将永久封门，叛军准备炸毁隔离墙，避难所底层同步塌方。Alice 的选择决定后续路线；她可随帝国封控、随叛军冲关，或先救援塌方区，为深岩联合体埋下基础。
6. **叛军线：名字的重量（Alice/Bob/Charlie）**：选择救援或冲关后的连锁后果。选择帝国的旧队友成为正面敌手，但其目标是阻止更大规模的扩散与战争。
7. **帝国线：安静的胜利（Alice/Bob/Charlie）**：选择封控后的连锁后果。选择叛军的旧队友成为正面敌手，但其目标是让被注销的人仍有出路。
8. **深岩之下（Alice）**：第三条路的基础。工人、医生与边缘工程师尝试以局部隔绝、减毒改造和自给生态维持生存；他们不是完美答案，只是拒绝继续被两端定义。
9. **终局：航路仲裁者（分支双结局）**：叛军线面对选择帝国的队友；帝国线面对选择叛军的队友。帝国伪造感染名册、操控航迹与扩大净化范围的证据在此汇合，但锈蚀症作为真实风险也迫使所有人面对自身的扩张代价。战斗后的结果不是道德审判，而是由幸存者承担具体、持续的代价。

## 关键对白原则

- 对白必须改变人物关系、暴露价值冲突或推动行动，避免用口号重复阵营立场。
- 每个核心抉择至少包含：一个具体可见的受害者、一个可预见的系统性风险、一个由旧日友谊带来的私人代价。
- 三人争执时都必须有一部分正确：Alice 看到眼前的人，也可能因炽热与鲁莽忽略队友的承受极限；Bob 看到扩散、证据和机器接管判断的危险；Charlie 看到行动会留下的后果，也可能因害怕失去而错过必须行动的时机。
- 帝国谎言的揭露应由航迹、净化名单、AI 指令链和黑匣协议碎片逐层完成；锈蚀症的来源只提供可相互印证的线索，不把它简化成某一方的单独罪行。
- 不直接展现处决或屠杀过程；通过中断的通讯、航迹、物资记录、环境和人物反应呈现伤害。
