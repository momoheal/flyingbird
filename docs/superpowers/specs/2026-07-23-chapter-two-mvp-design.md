# 第二章 V3 设计：检疫井之前

## 重构目标

第二章的主线必须回答四个问题：玩家为什么去 B 区、为什么必须护送这些船、为什么此刻必须选择、为什么选择会召来不同 Boss。答案全部在战斗中发生，不依赖玩家阅读长文档。

## 因果链

```text
第一章航迹矛盾
-> 军需官发现 A 区残骸属于同一支转运队
-> 玩家奉命护送转运队进入 B 区检疫井
-> 救援浮标让玩家听见船队内部的家属频道
-> 三次扫描证明“矿船”其实是被注销身份的平民转运队
-> 帝国要求交船并启动净化
-> 玩家选择开舱救人或执行接管
-> 对应阵营立刻派出 Boss 阻止/完成这件事
-> Boss 战的胜利决定本章代价与第三章方向
```

## 第一章到第二章的衔接

第一章结尾，战报声称缝合航母撞击逃生舱；玩家角色通过航迹看到航母三次朝外转向，实际上在挡碎石。军需官检查左舷擦痕后确认这不是主观猜测，并在残骸导航缓存中找到一支从 A 区撤出的“矿务转运队”编号。B 区是它们唯一能到达的检疫井，因此玩家被要求护送这支队伍回收，不是凭空接受新任务。

军需官不会说“船里是难民”，只说明清单、航线和残骸编号互相矛盾。玩家必须在战斗中确认事实。

## 共通战斗段：护送转运队

玩家护送三艘被伪装成矿船的转运船穿越 B 区碎石带。四波敌人攻击的是船队，不是玩家的抽象分数；敌人撞击船体会减少船队完整度。第一波结束时，一艘失控穿梭艇坠入航线，玩家救下它后获得民用救援浮标，短暂听见船内家属频道的呼叫。

玩家随后靠近三艘转运船完成扫描，证据按顺序推进：

1. 货舱原始标签为“紧急转运”，矿物读数是伪造的。
2. 船内生命热源远超船员编制，说明整船都在载人。
3. 身份码被整批删除，逃生门从内部锁死；B 区检疫井不是避难所，而是净化流程的入口。

扫描完成后，帝国频道下达明确命令：护航任务结束，把转运队交给检疫井，禁止打开货舱。倒计时显示净化接管将在三十秒后启动。军需官只发送一次未签名跃迁坐标，玩家必须选择。

## 分支一：开舱救人 / 帝国封锁舰“赦令”

玩家拒绝交船，打开一艘货舱，民用频道短暂恢复。帝国判定玩家叛乱，审判级封锁舰“赦令”从检疫井跃迁出来。它不是来谈判的，而是用牵引束把三艘船推入恒星引力井。

- 阶段一：击破三处锁定节点，让运输船逐艘恢复推进。
- 阶段二：封锁舰展开炮阵，军需官投放过载核心，玩家在火力走廊中抢到临时高伤害。
- 阶段三：核心暴露，玩家击断最后牵引梁，护送最后一艘船穿过跃迁窗。

Boss 被击败后不是“正义胜利”，而是玩家正式失去帝国身份；运输船带着救援浮标和家属频道进入未知航线。第三章预告：原队友接受晋升，奉命截断玩家退路。

## 分支二：执行接管 / 叛军突入舰“归航者”

玩家接受命令，封锁阵列启动。叛军从家属频道的求救信号中定位船队，突入舰“归航者”强行跃迁进场。它不是来单纯救人：它用运输船当掩体、发射拖曳钩，准备把整支船队拖入自己的火线。

- 阶段一：击断拖曳缆索，守住帝国封锁锚点。
- 阶段二：归航者投放登舰艇和自爆拖曳器，玩家获得一次帝国拦截火力清屏。
- 阶段三：击毁过载推进核心，迫使归航者脱离；封锁阵列完成接管。

Boss 被击败后，帝国宣布转运队已被接管，运输船信号逐一熄灭。画面不展示处决，但玩家知道自己让净化流程继续。第三章预告：原队友拒绝后续命令，接管 B 区叛军。

## 角色作用

- Alice：先听见家属频道中的儿童呼叫，选择保护时由“宣誓”转为主动背叛；选择执行时保留一条本地加密记录。
- Bob：从三个扫描结果建立可验证结论；选择保护是承认命令与事实冲突，选择执行是把记录复制进黑匣。
- Charlie：认出检疫井与早期边境战的旧编号；选择保护是留下来挡住封锁，选择执行则要求给船队三十秒准备。

## 对话和文档规则

运行时唯一台词源仍是 `docs/dialogue-story.md`。每句台词必须完成至少一个功能：交代目标、改变判断、触发行动或表达代价。禁止只用“战争很残酷”“有些数字无法修复”等抽象句替代事实。

V3 事件 ID：`ch01.debrief`、`ch02.quartermaster.armor`、`ch02.quartermaster.manifest`、`ch02.rescue_float`、`ch02.scan.1`、`ch02.scan.2`、`ch02.scan.3`、`ch02.choice.order`、`ch02.rebel_boss.*`、`ch02.empire_boss.*`。

## 验收标准

1. 不读外部设计文档，玩家仍能通过战斗和通讯复述“为什么护送、船里是什么、为什么必须选择”。
2. 每个 Boss 出场都有明确触发源：保护线来自帝国净化接管，执行线来自叛军截获家属频道。
3. 两条线的 Boss 目标、弹幕机制、奖励、胜利画面和第三章预告均不同。
4. 选择不是结算按钮；第二章只有击败对应 Boss 后才完成。
5. 第一章、Markdown 加载、失败重试和素材检查不回归。
## Faction and scan presentation contract

- Before the route choice, convoy escorts are rebel skiffs. The protection route changes escorts to imperial inspection drones; the execute route changes them to rebel interceptors.
- The B-sector scan corridor has a contrast frame, readable label, and high-contrast beacon so the scan objective is visible over the mining background.
