# 关卡收束与 GAL 对话框设计

## 目标

将原型收束为一条可理解、可通关的叙事纵切。玩家完成 A 区与 B 区调查后，必定抵达第 09 隔离关口；最终路线只在第五关作出。所有玩家可见文本使用中文。

## 关卡流向

```text
序章 -> 第一关 A 区 -> 整备 -> 第二关 B 区 -> 黑匣插章 -> 第五关第 09 隔离关口 -> 三个短终局
```

- 第一关保留救生舱、航母行为与伪造战报的证据链。
- 第二关只有护航、三次扫描、四波敌机和黑匣留存。不得出现阵营选择、第二关 Boss、第二关结局或“第三关预告”。
- 第二关成功后依次播放黑匣结果、锈蚀插章与玛拉求救，并自动进入第五关共同防守段。
- 第五关共同防守完成后，暂停并给出守住医疗门、打开封锁、救援塌方区三项行动。每项写明即时代价。
- 每条路线是独立的短任务；本关重试保留驾驶员但重置战斗状态，重新部署回到开场。

## 对话交互

### 关键对话

- 使用底部 `#dialogue-box`，而不是右上通讯面板。
- 每个关键事件由对话队列逐句呈现；战斗暂停，点击或按 Enter/Space 推进。
- 左侧固定显示当前驾驶员的头像、姓名和本句回应；右侧显示该事件的对话对象与头像、姓名和当前台词。
- 角色头像优先使用现有 Alice、Bob、Charlie、指挥频道与叛军指挥官素材；缺图人物使用统一系统终端或语义 emoji，如 `📡`、`🛠️`、`⚠️`，不得出现破图或空白头像。
- 不出现英文字段名、内部状态名、英文任务缩写或中英混排人物名。

### 战斗提示

- 普通击毁短句、扫描进度和技能提示使用短暂字幕/任务提示，不进入关键对话队列，也不暂停战斗。
- 右上角仅保留任务、血量、波次与当前短目标；不再承担长对白。

## 实现边界

- `docs/dialogue-story.md` 保持运行时对白唯一来源；增加显式的 `speaker` 中文显示名与头像键映射。
- 原型以单一叙事状态出口实现 B 区至插章再至第五关的转移，计时器必须受运行代号保护，重置后不得跳转。
- 删除或停用旧的 `CH02_CHOICE`、第二关 Boss、旧分支结局和相关可见文案；不以隐藏 UI 的方式保留它们。
- 第五关的选择界面也使用底部对话后的行动按钮，不再显示独立的通讯剧场卡片。

## 验收

1. 从部署开始可依次到达第二关、插章、第五关与任一短终局，无死路。
2. 第二关完成后不会出现阵营二选一、第二关 Boss 或章节预告卡。
3. 任意关键对话显示底部双人 GAL 框，左侧为当前驾驶员、右侧为对象或系统占位头像，且能逐句推进。
4. 原型中的玩家可见文本为中文；系统占位可使用 emoji。
5. 自动检查覆盖状态出口、中文 UI 文案、对话队列和旧第二关分支缺席；实际浏览器验收覆盖 B 区到第五关与一条终局。
